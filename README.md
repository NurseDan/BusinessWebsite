# Hill Country Health Ops Website

A static business website for a healthcare operations support concept serving Kerrville and the Texas Hill Country.

## Concept

Hill Country Health Ops helps small healthcare and behavioral health teams reduce administrative chaos by cleaning up workflows, documentation systems, staff process guides, and internal communication.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - navigation, form feedback, and small interactions

## Run locally

Open `index.html` in a browser.

For a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize before launch

- Replace placeholder email and phone number in `index.html`.
- Add the real booking link when Calendly or another scheduler is ready.
- Adjust the business name if you prefer `Clarity Health Ops`, `Wiglesworth Health Solutions`, or a personal Daniel Wiglesworth consultant brand.
- Connect the contact form to Formspree, Netlify Forms, a CRM, or a custom backend.
